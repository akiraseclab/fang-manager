# fang-manager 房源管理系统

多房东房源展示与租赁管理平台：房东在后台维护房源，系统为每套房源生成专属二维码，租客扫码即可在手机上查看图文详情并直接联系房东。

## 功能

- **多房东账号体系** — 手机号注册/登录，房源归属隔离，互不可见
- **房源管理** — 名称/价格/户型/面积/楼层/朝向/地址/描述，空置与已出租状态联动
- **照片与视频** — 多图上传自动压缩，视频自动转码 H.264（兼容 iPhone 微信内播放）
- **房源展示页** — 图集轮播 + 全屏浏览、基本信息四宫格、位置卡片（高德导航）、配套设施图标、房东联系卡片
- **二维码** — 每套房源专属二维码，内容随访问域名自动生成
- **租客服务（可按房东开关）** — 预约看房 / 维修申报 / 租客留言，房东端集中处理
- **租约到期邮件提醒** — 租期截止前 N 天自动发邮件通知房东，同一租期只提醒一次
- **房源展示为基础功能锁定**，其余服务模块房东可在设置页自由开关

## 快速开始

```bash
pip install -r requirements.txt
cp secret.txt.example secret.txt    # 第一行为 Flask 密钥，第二行为初始管理员密码
python app.py                       # http://127.0.0.1:5002
```

- 默认管理员：手机号 `13800000000`，密码 `admin123`（登录后请在个人资料中修改）
- 视频转码依赖服务器安装 [ffmpeg](https://ffmpeg.org)
- 生产部署建议 gunicorn + nginx，参考 `fang-manager.service` 与 `nginx.example.conf`，详见 `DEPLOY.md`

## 技术栈

Flask · SQLite · Jinja2 · 原生 JavaScript（无前端框架）· Pillow · qrcode · ffmpeg
